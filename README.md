# Tugas-Infinite-Learning

Setiap topik dibuat dengan 4 jenis function yang berbeda, sesuai dengan materi yang sudah dipelajari sebelumnya.

## Penjelasan Function

Pada setiap topik, terdapat 4 tipe function, yaitu:
- Function tanpa parameter dan tanpa return
- Function dengan parameter tanpa return
- Function tanpa parameter dengan return
- Function dengan parameter dan return

Tujuan dari pembuatan variasi ini adalah untuk memahami perbedaan cara kerja function dalam Python.

## Penjelasan Tiap Topik

### 1. Menyapa
Berisi function sederhana untuk menampilkan pesan sapaan kepada pengguna. Beberapa function langsung menampilkan hasil, dan beberapa mengembalikan nilai.

### 2. Kalkulator Luas Persegi
Digunakan untuk menghitung luas persegi dengan rumus:
Luas = sisi × sisi

Function dibuat dengan berbagai variasi agar lebih memahami penggunaan parameter dan return.

### 3. Kalkulator Diskon
Digunakan untuk menghitung harga setelah diskon dengan rumus:
Total = harga - (harga × diskon / 100)
